# AQI Category Prediction

An ML-based Air Quality Index (AQI) category prediction project using CPCB air quality data. This repository includes data preprocessing, exploratory data analysis (EDA), feature engineering, and multiple classification models.

## Models Included
* Random Forest
* Support Vector Machine (SVM)
* Decision Tree
* Logistic Regression

## Project Structure
* `data/` - Raw and processed datasets
* `models/` - Saved trained models
* `notebooks/` - Exploratory Data Analysis and training experiments
* `app.py` / `predict.py` - Model inference and API scripts
* `Dockerfile` - Containerization setup
